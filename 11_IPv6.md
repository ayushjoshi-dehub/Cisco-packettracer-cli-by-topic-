# IPv6 Implementation (Static Addressing + RIPng)

## Topology Diagram

```
2001:AA1::/64                    2001:AA2::/64                    2001:AA3::/64
+-----+ +-----+ +---------+  Gi0/1(::1)   Gi0/1(::2)  +---------+  Gi0/0(::1)  +-----+
| PC1 | | PC2 |-| Router1 |------------------------------| Router2 |------------| PC3 |
+-----+ +-----+ +---------+                              +---------+           +-----+
   |                Gi0/0(::1)
+---------+
| Laptop1 |         Server1: 2001:AA1::5/64          Server2: 2001:AA3::2/64
+---------+

RIPng process tag "cisco" enabled on every routed interface
```

## Router 1

```
Router>enable
Router#configure terminal
Router(config)#ipv6 unicast-routing

Router(config)#interface gigabitEthernet 0/0
Router(config-if)#ipv6 address 2001:AA1::1/64
Router(config-if)#no shutdown
Router(config-if)#ipv6 rip cisco enable
Router(config-if)#exit

Router(config)#interface gigabitEthernet 0/1
Router(config-if)#ipv6 address 2001:AA2::1/64
Router(config-if)#no shutdown
Router(config-if)#ipv6 rip cisco enable
Router(config-if)#exit
```

## Correction / Note

The original notes wrote addresses like `2001:AA1:1/64` — real IPv6 syntax needs a double
colon to expand the compressed zero groups, e.g. `2001:AA1::1/64` (a single colon is
invalid/ambiguous and Packet Tracer will reject it). Also, `ipv6 unicast-routing` is a
one-time global command needed before RIPng or any IPv6 routing protocol will work — it
was missing from the original notes. The RIPng process tag (`cisco`) just needs to match
on every router in the domain; it can be any name you choose.
